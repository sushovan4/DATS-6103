Decision Trees


45 minutes

Decision trees are defined by recursively partitioning the input space, and defining a local model in each resulting region of the input space. Consequently, the overall model can be represented by a tree.

Although decision trees can also be used for regression, we study here only classifiers trees.

Trees

Trees are special graphs with a designated root node and no cycles.

Decision Trees are Everywhere!

It’s quite common in real life to use nested decision rules or a decision tree for making day-to-day choices.

Mathematical Formulation

Let us consider a classification problem with features \bold{x}=(x_1, x_2, \ldots, x_d) and class labels \{{\tt 1}, {\tt 2}, \ldots, {\tt C}\}.

The idea behind decision tree is to divide the feature space \mathcal{X} into non-overlapping regions \mathcal{T}=\{\mathcal{R}_i\}, where each region \mathcal{R}_i is given by

  1. a sequence of nested conditions each defined by a threshold t\in\mathbb{R} (e.g., x_i\leq t_i, etc)
  2. a class label \tt c_j\in \{{\tt 1}, {\tt 2}, \ldots, {\tt C}\}.

The regions are commonly taken to be rectangular (axis-parallel) and entire the decision boundary looks like a colored maze.

For example, below is a decision tree for a two-dimensional feature vector \bold{x}=(x_1, x_2) and three class labels \{{\color{orange}\tt 0}, {\color{green}\tt 1}, {\color{royalblue}\tt 2}\}. See ; see Figure 2.

Training

To obtain such a decision tree, we use training data \mathcal{D} to meaningfully choose a sequence of features and thresholds that minimizes some notion of loss. The two commonly used loss functions are Gini (Equation 2) and Entropy ((Equation 3)). See [Subsection](#the-training-algorithm-(optional) for more details.

The Training Algorithm (Optional)

Training the perfect split of the feature space that minimizes loss is known to be an \mathcal{NP}-hard problem. The standard approach is to use a greedy procedure, in which we iteratively grow the tree one node at a time.

Step: i\geq1

Suppose we are at node i; let \mathcal{D}_i=\{(\bold{x}_n, y_n)\in N_i\} be the subset of the training data that reaches the node. We consider how to split this node into a left branch and right branch so as to minimize the training error in each child subtree.

  1. We first sort the unique values of the jth feature x_j in \mathcal{D}_i to get the set of all possible thresholds \mathcal{T}_{j}=\{x_{nj}\} for x_j.

  2. For each possible threshold t\in\mathcal{T}_j, define the left and right splits, respectively: \mathcal{D}_i^L(j, t)=\{(\bold{x}_n, y_n)\in N_i\mid x_{n,j}\leq t\},\text{ and} \mathcal{D}^R_i(j, t)=\{(\bold{x}_n, y_n)\in N_i\mid x_{n,j}> t\}.

  3. Finally, to find the best split at node i, we choose the best feature x_{ji} and threshold t_i that minimizes the following loss: \mathcal{L}_i(j, t)=\frac{\mathcal{D}^L_i(j,t)}{\mathcal{D}_i}{\tt cost}(\mathcal{D}^L_i(j,t)) + \frac{\mathcal{D}^R_i(j,t)}{\mathcal{D}_i}{\tt cost}(\mathcal{D}^R_i(j,t)). \tag{1} Here, the cost {\tt cost}(\mathcal{D}_i) is computed by Gini index as described below.

Gini and Entropy

Let us consider any node with data \mathcal{D}_i. We first compute the empirical distribution over class labels for this node: \hat\pi_{ic}=\frac{|\{ n\in\mathcal{D}_i\mid y_n=c\}|}{|\mathcal{D}_i|}. From this, we can define the Gini index. G_i=\sum_{c=1}^C\hat\pi_{ic}(1-\hat\pi_{ic})=1-\sum_{c=1}^C\hat\pi_{ic}^2. \tag{2} Alternatively, the entropy is defined by H_i=-\sum_{c=1}^C\hat\pi_{ic}\log{\hat\pi_{ic}}. \tag{3}

In Equation 1, one of the above cost description can be used to compute the loss used by the decision tree algorithm.

  const gini = (left_n/n) * left_gini + (right_n/n) * right_gini;
  return gini;

Feature Importance

For a decision tree \mathcal{T}, the feature importance of the feature x_k is defined by its total contribution in reducing impurity or Gini.

Let us assume that the feature x_k appears in J many internal nodes of the decision tree \mathcal{T}. The contribution or importance of x_k in reducing impurity at node the jth node can be defined as: {\tt Imp_k(j)}=\frac{|\mathcal{D}_j|}{|\mathcal{D}|}G(\mathcal{D}_j) -\left(\frac{|\mathcal{D}_j^L|}{|\mathcal{D}|}G(\mathcal{D}_j^L) +\frac{|\mathcal{D}^R_j|}{|\mathcal{D}|}G(\mathcal{D}_j^R)\right). Adding the contributions from all the J nodes, we get the feature importance of the feature: {\tt Imp_k(j)}=\sum_{j-1}^J{\tt Imp_k(j)}.

function findNode(tree, id) {
  if(tree.id === id)
    return tree;
  if(!tree || tree.type === 'leaf')
    return null;
  return findNode(tree.left, id) || findNode(tree.right, id);
}

function dataAtNode(tree, node, data) {
    const res = [];
    if(tree.id === node.id)
      return data;
    if(tree.type === 'leaf')
      return [];
    const leftData = data.filter((d) => d[tree.feature] <=  tree.value);
    const rightData = data.filter((d) => d[tree.feature] >  tree.value);
    res.push(...dataAtNode(tree.left, node, leftData));
    res.push(...dataAtNode(tree.right, node, rightData));
    return res;
}
function regionAtLeaf(tree, node, rect) {
    if(!node)
      return {x1: -Infinity, x2: Infinity, y1: -Infinity, y2: Infinity};
    if(tree.type === 'leaf' && tree.id === node.id)

      x2: Math.min(left.x2, right.x2),
      y1: Math.max(left.y1, right.y1),
      y2: Math.min(left.y2, right.y2)
    };
}

  const gridSize = 80;

function findLeaf(tree, p) {
  let node = tree;
  while (node.type === 'split') {
    node = p[node.feature] <= node.value ? node.left : node.right;
  }
  return node;
}
treeData = function(tree, features=['x_1', 'x_2'], predict=false, data=null) {
  function flatten(node, depth = 0, parentPath = 'Node_') {
    const currentPath = parentPath ? `${parentPath}/Node_${node.id.toString()}` : node.id.toString();
    let label = node.label;
    let name = node.name;
    if(node.type === 'leaf' && predict) {
      const count = getCount(tree, node, data);
      name = Object.entries(count).map(([k, v]) => `${k}: ${v}`).join(', ');
      label = Object.keys(count).reduce((a, b) => {
            return count[a] > count[b] ? a : b;
      });
    }
    const nodes = [{
      path: currentPath,
      name: name,
      type: node.type,
      label: label,
      depth: depth
    }];
    
    if (node.left) {
      nodes.push(...flatten(node.left, depth + 1, currentPath));
    }
    if (node.right) {
      nodes.push(...flatten(node.right, depth + 1, currentPath));
    }
    
    return nodes;
  }
  
  return flatten(tree);
}

function leaves(tree) {
  const l = []
  if(tree.type === 'leaf') {
    l.push(tree);
    return l;
  }
  l.push(...leaves(tree.left));
  l.push(...leaves(tree.right));

  return l;
}

Impurity, by hand

A node holds 30 examples: 18 of class 0 and 12 of class 1. Its Gini impurity is

G = 1 - \sum_c p_c^2,

where p_c is the proportion of class c in the node. Write gini(counts) taking an array of class counts and returning the impurity.

def gini(counts):
    p = np.asarray(counts, dtype=float) / np.sum(counts)
    return 1 - np.sum(p ** 2)
